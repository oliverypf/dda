项目归档状态保存在本机应用存储中，不是目录删除或跨设备同步。

## 从失败中加入的 harness

| 实际问题 | 已加入运行时的处理 |
| --- | --- |
| 使用未获准命令，错误缺少下一步 | 工具描述提供获准可执行文件；拒绝结果保留错误码并给出读取工具或正确命令调用指引 |
| 持续读源码，迟迟不实施 | 每 8 个新读取结果给出进度检查点；确认缺失证据，按用户目标决定小步修改或继续分析 |
| 小补丁无法修改约 375 KB 的源文件 | 区分替换片段上限与整文件上限，支持既有执行器允许的 1 MiB 文件 |
| 文件已写入，却因返回 diff 太大报告失败 | 限制 JSON 编码后的差异预览大小，保留完整内容摘要及截断标记 |
| 找函数需要多次分页 | `workspace.read` 增加受限的 `findText` 字面定位，返回实际字符位置和有界片段 |

监督者实现并测试这些通用机制。它们不绕过工作区权限、逐次写入授权或 Jev，也不自动把失败运行、统计信息或未验收建议存成已验证记忆。
