## 这轮发现并修复的缺陷

- 文件 patch/diff 读取超出底层单页限制：改为完整分页读取、稳定摘要与大小限制，防止只读取前段后覆盖完整文件。
- 执行器把失败测试当成功工具：现按真实退出结果分类，只有同一测试随后成功且具备原生证据才解决该失败；硬失败仍停止。
- 未许可工具被展示给模型、合法 `cwd="."` 被拒绝：现在按许可展示工具并接受工作区根目录，越界路径及未许可执行继续拒绝。
- 网络瞬断：仅在未开始输出时有限重试可恢复网络／HTTP 状态，拒绝重放部分流和认证失败。
- Jev 请求地址与 schema 不兼容：旧地址 404、旧字段 422；已按 [官方 API schema](https://api.typesafe.ai/openapi.json) 修复为 `/v1/systemone` 与 criteria/instructions。相同 SDK 三次真实调用全部成功，返回模型 `jev-1.13.0`，延迟 1348／339／649 ms；完整工作流收益未测试。[真实调用记录](C:/Users/User/hmCodex-local/docs/artifacts/GOAL_STAGED_JEV_LIVE_2026-10-07.json)。
- 任务摘要的六按钮拥挤及未知指标显示：按钮可换行，未报告 token／费用明确显示未知。
- 工作区快照偶尔扫描到正在删除的取消锁：在解析路径前精确排除自身存储及锁文件，未放宽其他文件错误。
- 测试超时后仍等待继承管道：增加有界收尾，保留不完整输出标记，避免一键验收永久等待。
