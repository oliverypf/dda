独立验收中，三次都允许普通刷新、检测真实暂存和配置变化，三份受保护的原测试也分别为 3/3。链接处理是对最终源码的核对，这三项独立验收没有专门构造链接替换。三次客户端最终都因结论验证器返回 `UNCERTAIN` 而退出失败。对照上批同余额的 **1/3**，本批修对 **3/3**；只有第 3 次提供了被拒后改对的证据。三次独立采样无法衡量单个提示或字段的独立贡献。[本批验收及客户端终态](results.json) · [上批候选与回执](../git-fingerprint-prepatch-2026-11-21/decisions.md)
